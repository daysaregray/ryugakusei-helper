## 한국어

일본에서 생활하는 유학생을 위한 생활 정보 웹 앱입니다. 한국어와 영어를 지원합니다.

매 학기 한국인 후배들에게 쓰레기 분리수거, 전입신고, 국민건강보험, 병원 이용 방법 같은 같은 내용을 반복해서 설명해야 했습니다. 이 내용을 한곳에 모아, 새로 온 유학생이 스스로 찾아볼 수 있도록 만들었습니다.

### 주요 기능

- **생활 정보 검색**: 쓰레기, 구청·시청, 병원·약국, 전기·수도·인터넷 4개 분야 14개 항목. 순서, 준비물, 일본어 용어, 출처를 함께 안내합니다.
- **오늘 버리는 쓰레기**: 우리 동네 배출 요일을 설정하면 오늘과 내일 버릴 수 있는 쓰레기를 보여줍니다.
- **일본어 표현 도우미**: 6개 상황, 33개 문장. 복사, 음성 듣기, 크게 보여주기를 지원합니다.
- **유학생 커뮤니티**: 질문과 답변 게시판. 전화번호나 이메일이 들어간 글은 올리지 않도록 경고합니다.
- **즐겨찾기**: 자주 보는 정보와 문장을 저장합니다.
- **한국어 / English 전환**

### 사용 기술

HTML, CSS, JavaScript (파일 하나: `index.html`)

### 참고

이 GitHub Pages 버전에서는 게시판이 미리보기 모드로 동작합니다. 쓴 글은 그 화면에만 보이고 저장되지 않습니다. 즐겨찾기와 쓰레기 요일 설정은 각자의 브라우저에 저장됩니다. 게시판 글을 모두가 함께 보려면 Firebase 같은 데이터베이스 연결이 필요합니다.

## 日本語

日本で暮らす留学生のための生活情報ウェブアプリです。韓国語と英語に対応しています。

毎学期、韓国人の後輩たちに、ごみの分別、転入届、国民健康保険、病院の受診方法など、同じ内容をくり返し説明しなければなりませんでした。そこでこれらの情報を一か所にまとめ、新しく来た留学生が自分で調べて解決できるようにしました。

### 主な機能

- **生活情報の検索**：ごみ、役所、病院・薬局、電気・水道・インターネットの4分野、計14項目。手順、持ち物、日本語の用語、出典をまとめて案内します。
- **今日のごみ**：地域のごみ収集日を設定すると、今日と明日出せるごみを表示します。
- **日本語表現ヘルパー**：6つの場面、33の文。コピー、音声再生、大きく表示に対応しています。
- **留学生コミュニティ**：質問と回答の掲示板。電話番号やメールアドレスが含まれる投稿には注意を表示します。
- **お気に入り**：よく見る情報や文を保存できます。
- **韓国語 / 英語の切り替え**

### 使用技術

HTML、CSS、JavaScript（ファイルは `index.html` の1つのみ）

### 注意

GitHub Pages版では、掲示板はプレビューモードで動作します。投稿はその画面にだけ表示され、保存されません。お気に入りとごみの収集日の設定は、各自のブラウザに保存されます。掲示板の投稿をみんなで共有するには、Firebaseなどのデータベースとの連携が必要です。

## English

A life-information web app for international students living in Japan. Available in Korean and English.

Every semester I had to explain the same things to new Korean students over and over: garbage sorting, resident registration, National Health Insurance, how to visit a clinic, and more. I put all of this in one place so that newly arrived students can find the answers on their own.

### Features

- **Life info search**: 14 guides in 4 areas (garbage, city hall, clinics and pharmacies, utilities and internet), with steps, what to bring, useful Japanese terms, and sources.
- **Today's garbage**: set your area's collection days to see what you can put out today and tomorrow.
- **Japanese phrase helper**: 33 sentences for 6 situations, with copy, audio playback, and a large-text view to show staff.
- **Student community**: a Q&A board that warns you before posting phone numbers or email addresses.
- **Saved items**: keep the guides and phrases you use most.
- **Korean / English switch**

### Built with

HTML, CSS, JavaScript (a single file: `index.html`)

### Note

On this GitHub Pages version, the community board runs in preview mode: posts appear only on your own screen and are not saved. Saved items and garbage day settings are stored in each person's browser. Sharing posts between users requires a database such as Firebase.
